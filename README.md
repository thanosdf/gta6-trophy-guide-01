An offline GTA 6 trophy guide and tracker covering all 55 official trophies. It lists every trophy with its official name, description and grade, lets you tick off the ones you have earned, filter by kind and grade, search, hide story spoilers until you earn them, and follow a roadmap to the platinum with the missables flagged. Each trophy has its own guide written in plain words, with its sources cited. Your progress is saved in your browser, and you can export it or import it on another machine. Everything runs from local files, so it works with the network off.

## Run it

Serve the `app` folder with any static file server, for example:

```sh
npx serve app
```

then open the address it prints in your browser.
